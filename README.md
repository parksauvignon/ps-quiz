# Квіз «Парк Совіньйон» — прототип посадкової сторінки

Односторінковий опитувальник для окремої кампанії в Meta. Уся сторінка — це квіз:
7 питань (1:1 з чинної лід-форми Meta) + екран контактів. Нічого зайвого, на що можна відволіктись.

**Демо:** https://parksauvignon.github.io/ps-quiz/
**Режим налагодження:** додати `?debug=1` — унизу зʼявиться панель подій (видно, на якому кроці і скільки часу провів користувач).

---

## Що всередині

| | |
|---|---|
| Вага | один HTML-файл, інлайн CSS/JS, без зовнішніх скриптів; ~58 КБ + 3 шрифти (88 КБ) |
| Візуальний світ | успадкований з лендингу єОселя: 5 брендових кольорів, ProbaPro 400/500/600, без курсиву |
| Сцена | авторська SVG-ілюстрація, яка **збирається з відповідей**: тип квартири → планування у виносці, ремонт → меблі, стадія → кран або вхідна група, район → море й місто, тип будинку → силует, важливе → майданчик/алея/паркінг/охорона, час дзвінка → сонце по дузі й теплота неба |
| Взаємодія | автоперехід після вибору, мультивибір з кнопкою «Далі», «Назад», клавіші 1–9 / Enter / Backspace, легка вібрація на дотик, чіпи відповідей із поверненням до питання |
| Відновлення | стан у `localStorage`: користувач повертається — пропонуємо продовжити з того самого питання |
| Підбірка | після 7 питання показуємо реальні лоти із залишків CRM і ціни в гривні, повна підбірка — після номера |
| Вихід для гарячих | кнопка «Зателефонувати» у шапці — хто не хоче квіз, дзвонить одразу |

## Перед запуском (обовʼязково)

1. **`CONFIG.rate`** — актуальний курс ₴/$ (зараз 42,8). Усі ціни рахуються з нього.
2. **`CONFIG.phone`** — робочий номер відділу продажу (зараз заглушка).
3. **`CONFIG.stock`** — залишки з G-Plus CRM (зараз зріз 01.09.2026). Оновлювати щомісяця.
4. **`CONFIG.crm.enabled = true`** + токен. ⚠️ Зараз `false` — прототип нічого не шле в бойову CRM,
   а друкує майбутню картку ліда в консоль. Токен тримати на проксі (Apps Script/сервер), **не в HTML**.
5. **Meta Pixel / GA4 / Google Ads** — вставити теги в `<head>`. Подія `Lead` має спрацьовувати
   **лише після підтвердження від CRM**, інакше повторимо історію з фейковими конверсіями на `/kontaktyi.html`.
6. **Ціни** — узгодити з відділом продажу. У рекламі й на посадкових сторінках лише гривня.

## Події аналітики

`quiz_start` · `quiz_step_view` · `quiz_answer` · `quiz_back` · `quiz_chip_edit` · `quiz_resume` ·
`quiz_restart` · `quiz_phone_focus` · `quiz_validation_error` · `quiz_contact_view` · `quiz_submit` · `quiz_done` · `phone_click` · `bot_click`

Кожна подія несе номер кроку, id питання, значення відповіді та час на кроці (`ms`).
Саме з них будується воронка «на якому питанні обривається заповнення».

## Картка ліда в CRM

`note` починається з маркера **`КВІЗ META`** — щоб у дашборді відрізняти квіз від форми сайту
(зараз CRM їх не розділяє, ділимо за текстом). Далі — усі питання з відповідями, спосіб звʼязку та UTM.

## Локальний запуск
